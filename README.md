# Student_Data_Analysis_Using_Python

Student Data Analysis Using Pandas

Project Overview

This project focuses on exploring and analyzing student data using Python and the Pandas library. It covers essential Pandas operations used in data analysis, including data inspection, cleaning, statistical analysis, filtering, sorting, and data manipulation.

Tools & Technologies

- Python
- JupyterLab
- Pandas

Tasks Performed

1. Display the first 3 rows using "head()".
2. Display the last 3 rows using "tail()".
3. Find the shape of the DataFrame.
4. Get DataFrame information using "info()".
5. Check missing values using "isnull()".
6. Generate descriptive statistics using "describe()".
7. Find unique values in the Gender column.
8. Count unique values using "nunique()".
9. Count individual gender values using "value_counts()".
10. Filter students scoring between 90 and 100 using "between()".
11. Calculate the average marks.
12. Create a new column containing half marks using "apply()".
13. Create a Male_Female column using "map()" (Male = 1, Female = 0).
14. Drop unnecessary columns.
15. Display DataFrame column names.
16. Sort student records based on marks.
17. Display the names and marks of female students.

Learning Outcomes

- Understanding Pandas DataFrames.
- Exploring and inspecting datasets.
- Handling missing values.
- Performing statistical analysis.
- Applying filtering and sorting techniques.
- Creating and modifying DataFrame columns.
